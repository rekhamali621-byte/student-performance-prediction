# Student Performance Prediction Using Python

## About My Project

I made this project to learn how Python can be used in Data Science. It predicts student marks based on study hours.

## Tools I Used

* Python
* Pandas
* Matplotlib
* Scikit-learn

## What My Project Does

* Creates a small dataset of study hours and marks.
* Displays and analyzes the data.
* Shows a graph of study hours and marks.
* Uses Linear Regression to predict marks.
* Calculates model evaluation scores.

## Example

If a student studies for 6 hours, the model predicts their score using the sample data.

## What I Learned

While making this project, I learned how to work with data, create graphs, and use a basic Machine Learning model in Python.

## How to Run

Install the required libraries:

`pip install pandas matplotlib scikit-learn`

Then run `student_performance_prediction.py` in Python or Spyder.

**Note:** The dataset is created for practice and learning.
